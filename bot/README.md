# Бот «Школярик» — щоденні пости в Telegram

Канал: https://t.me/mypidruchnyk_ua · бот: @IIIkoJI9R1k_bot

## Що публікує
1. **Перші 7 днів** (від `guide_start` у `config.json`) — гайд по сайту, по одному посту на день: `guide/01.html … 07.html`.
   Якщо того дня сайт оновлювали — унизу поста коротко «А ще за добу на сайті: …».
2. **Далі щодня — «🧠 Питання дня»**: вікторина Telegram (4 варіанти, правильна відповідь і пояснення після вибору)
   з термінів «Запам'ятай» у тезах; предмети чергуються, питання не повторюються (~2600 термінів — на роки).
   Кнопка «📖 Відкрити сторінку» веде на сторінку підручника на сайті. Вимкнути — `"quiz_daily": false`.
3. **І, якщо були зміни,** — «Оновлення сайту»: що нового за добу (з повідомлень комітів), версія, які частини сайту зачеплено,
   скільки нововведень і виправлень. Немає комітів — немає поста. Коміти лише в `bot/`, `.github/`, `README.md` не рахуються.

Пости — у HTML-розмітці Telegram (`<b>`, `<i>`, `<a href>`), з кнопками «Відкрити сайт» і «Чат».
Щоб пост про оновлення був зрозумілим, пишіть повідомлення комітів людською мовою:
заголовок — що змінилось, нижче пункти `- …`.

## Як запускається
GitHub Actions (`.github/workflows/telegram-daily.yml`) щодня о 07:00 UTC (09:00 за Києвом узимку).
Потрібен секрет репозиторію **TELEGRAM_BOT_TOKEN** (Settings → Secrets and variables → Actions → New repository secret).

Вручну: вкладка **Actions → «Telegram — щоденний пост» → Run workflow** (за замовчуванням лише показ без надсилання).

## Локально
```
python bot/post.py --dry-run              # що вийде сьогодні
python bot/post.py --dry-run --day 3      # пост гайду № 3
python bot/post.py --dry-run --quiz        # «Питання дня»
python bot/post.py --dry-run --updates --since 7d   # пост про оновлення за 7 днів
python bot/post.py --token-file <файл з токеном>    # справжня публікація
```

## Налаштування (`config.json`)
- `channel` — канал для постів;
- `group_chat_id` — числовий ID чату: туди пост пересилається з каналу (`null` — не пересилати);
- `chat_url` — посилання для кнопки «Чат»;
- `guide_start` — дата першого поста гайду (UTC);
- `post_hour_utc` — година поста (має збігатися з cron у workflow);
- `quiz_daily` — щоденне «Питання дня» після гайду.

## 📊 Аналітика сайту — лише власнику (`analytics.py`)
Щодня в тому ж запуску бот надсилає **у приватні повідомлення власнику** (не в канал і не в чат) звіт за вчора:
відвідувачі (і зміна до позавчора), за 7 днів, популярні предмети, пройдені тести, країни, системи.
Цифри — з GoatCounter (лічильник `assets/stats.js` на сайті, анонімний, без cookie).

Налаштування:
- `config.json` → `goatcounter_code` — код сайту в GoatCounter (те саме, що `GC_CODE` у `assets/stats.js`);
- секрети репозиторію: `GOATCOUNTER_TOKEN` (API-ключ GoatCounter), `TELEGRAM_OWNER_ID` (ваш Telegram ID).
Без них крок тихо пропускається. Перегляд вигляду звіту: `python bot/analytics.py --sample`.
